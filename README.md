# Portfolio

Personal site. Single-page, no framework, no build step.

- `index.html` contains everything: markup, styles, and inline SVG brand icons
- `profile.jpeg` is the avatar

Light and dark themes, respects system preference with a manual toggle.

## Run

Open `index.html` in a browser. That's it.

## Deploy

Push to a repo and enable GitHub Pages on the default branch, or drop both
files into Netlify, Vercel, or Cloudflare Pages.
